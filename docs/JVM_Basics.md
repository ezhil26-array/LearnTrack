What is JDK, JRE, JVM?
JDK is java development environment. This is the tells which version of the Java the application is developed.
JRE is Java runtime environment. This is the set of  libraries in the execution environment.
JVM is Java virtual machine which responsible for executing the bytecode.

What is bytecode?
Bytecode is the machine code produced on compilation of the Java file.

What does “write once, run anywhere”
Java is developed using JDK and the files are compiled to bytecodes which are class files. 
These class files can be executed on any OS/Platform where Java virtual Machine is available.
This ensures 'write once, run anywhere'.
